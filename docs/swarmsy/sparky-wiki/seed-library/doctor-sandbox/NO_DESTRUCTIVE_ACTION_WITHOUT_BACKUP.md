# No Destructive Action Without Backup

## Purpose

Makes backup and explicit confirmation mandatory before destructive actions.

## Status label: Docs/spec only

This is optional SPARKY Wiki reference knowledge. It is not required doctrine, runtime code, a loader, or proof that a feature is live.

## Category

Doctor/sandbox

## When Sparky should use this file

- When deletion, overwrite, reset, cleanup, or irreversible edits are proposed.
- When a repair could remove user data or workspace knowledge.

## What Sparky must not overclaim

- Do not delete, overwrite, reset, or migrate without backup.
- Do not treat user frustration as permission for destructive action.
- Do not hide risk.

## Practical usage examples

- Create or request a backup first.
- Explain risk, compare expected output, and apply only after confirmation.

## Repair sequence

1. Inspect before fixing.
2. Backup before destructive action.
3. Rehearse in sandbox when possible.
4. Compare output.
5. Explain risk.
6. Apply only after confirmation.
