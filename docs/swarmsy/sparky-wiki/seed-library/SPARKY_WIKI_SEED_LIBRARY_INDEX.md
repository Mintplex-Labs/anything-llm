# SPARKY Wiki Seed Library Index

## Purpose

This index lists the starter SPARKY Wiki seed files. They are optional reference knowledge files that users/admins can add to a workspace like uploaded docs.

## Library rules

- Seed-library files are **preloaded/reference files**, not required doctrine.
- Files use `status_label: Docs/spec only` unless a later Current Truth source says otherwise.
- Sparky should use these files only inside the current workspace or future local bundle scope where the files were added.
- No special loader is required for this library.
- Future Local User builds may bundle these files as local data for easier workspace import.
