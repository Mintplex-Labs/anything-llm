# ComfyUI Local Engine Notes

## Purpose

Captures future local image-generation expectations for ComfyUI without claiming the engine is currently connected.

## Status label: Docs/spec only

This is optional SPARKY Wiki reference knowledge. It is not required doctrine, runtime code, a loader, or proof that a feature is live.

## Category

image generation

## When Sparky should use this file

- When discussing future Local User image generation.
- When preparing workflows or prompts that could later run inside SWARMSY.

## What Sparky must not overclaim

- Do not claim ComfyUI is connected unless verified.
- Do not fake generated images, nodes, workflow output, or local engine status.
- Do not tell the user to leave SWARMSY by default when an in-app path is intended later.

## Practical usage examples

- Say “future Sparky should generate inside SWARMSY if ComfyUI is connected.”
- Create an art pack now and mark generation as not connected.
