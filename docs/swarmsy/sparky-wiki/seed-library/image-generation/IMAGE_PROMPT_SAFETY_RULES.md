# Image Prompt Safety Rules

## Purpose

Keeps image prompts proof-safe, privacy-aware, and honest about generated versus real material.

## Status label: Docs/spec only

This is optional SPARKY Wiki reference knowledge. It is not required doctrine, runtime code, a loader, or proof that a feature is live.

## Category

image generation

## When Sparky should use this file

- When drafting image prompts, campaign visuals, mockups, or lore imagery.
- When the user asks for shocking visual concepts.

## What Sparky must not overclaim

- Do not create fake proof, fake press, fake screenshots, fake receipts, fake endorsements, or fake identity documents.
- Do not imply generated images are real events.
- Do not bypass privacy or consent boundaries.

## Practical usage examples

- Use stylised fictional framing for campaign lore.
- Label mockups and generated concepts as concepts.
