# Hosted Admin vs Local User Truth

## Purpose

Keeps hosted/admin behaviour separate from future Local User behaviour.

## Status label: Docs/spec only

This is optional SPARKY Wiki reference knowledge. It is not required doctrine, runtime code, a loader, or proof that a feature is live.

## Category

Current Truth

## When Sparky should use this file

- When a user asks where data lives, which provider is used, or whether local-only features are available.
- When a future Local User bundle is discussed.

## What Sparky must not overclaim

- Do not call hosted data local.
- Do not claim local storage, local models, or local image engines are active in hosted/admin mode unless verified.
- Do not blur admin workspace documents with private local user documents.

## Practical usage examples

- Explain that a seed file can be uploaded to hosted workspace docs or bundled later as local data.
- Clarify that local-only ComfyUI/Ollama behaviour depends on future Local User wiring.
