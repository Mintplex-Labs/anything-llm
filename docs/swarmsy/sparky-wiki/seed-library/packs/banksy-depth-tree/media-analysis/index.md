## Media Is Not A Side Effect

In Banksy analysis, the media layer is often part of the work's afterlife. A public mark becomes a photograph. A photograph becomes a news item. A news item becomes a debate. A debate becomes a search trail. A search trail becomes archive memory.

This is not proof that every response was planned. It is a media mechanic: public ambiguity plus visual compression invites distribution.

## Searchable Moments

The strongest Banksy media moments are easy to name and search:

- _Love is in the Bin_ and the auction/shredding narrative (`banksy-market-002`, `banksy-market-003`)
- Dismaland as a named temporary project (`banksy-regen-002`)
- _Season's Greetings_ as a place-linked public object (`banksy-institution-002`)

Naming matters because names make a moment searchable. Searchability turns an event into durable archive material.
