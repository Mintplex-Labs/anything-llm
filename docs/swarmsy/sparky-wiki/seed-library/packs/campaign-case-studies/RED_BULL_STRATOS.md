# Red Bull Stratos — Campaign Case Study

## One-line summary

Red Bull turned an extreme scientific/sporting mission into global media, proving the brand promise through the event itself.

## Why it worked

- the event embodied the brand idea
- suspense created live attention
- technical challenge created credibility
- athlete story gave a human anchor
- the mission produced news, video, stats, and replay value
