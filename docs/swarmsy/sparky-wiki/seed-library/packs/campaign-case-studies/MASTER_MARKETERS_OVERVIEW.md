# Master Marketers Overview

SPARKY Wiki does not need a random list of famous marketers. It needs a **pattern library** showing how strong visibility systems work.

## Core patterns to teach Sparky

| Pattern                         | Representative case | Why it matters to SPARKY Wiki                                          |
| ------------------------------- | ------------------- | ---------------------------------------------------------------------- |
| Research-led persuasion         | David Ogilvy        | Sell with facts, insight, proof, and respect for the audience.         |
| Opinion engineering / PR ethics | Edward Bernays      | Understand influence mechanics and guard against manipulation.         |
| Enemy positioning               | Apple “1984”        | Position a user against conformity, invisibility, or a stale category. |
| Universal motivational slogan   | Nike “Just Do It”   | Compress broad identity into a repeatable line.                        |
| Brand-as-media event            | Red Bull Stratos    | Build the stunt/event so media coverage becomes distribution.          |
| Scarcity / drops / subculture   | Supreme             | Control supply, community signal, and collaboration meaning.           |
| Mystery / public symbol         | Banksy              | Make the moment travel through curiosity and debate.                   |
