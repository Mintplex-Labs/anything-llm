# Canonical Questions Standard

Every release-track subject pack must include `canonical-questions.md`.

Purpose: prove Sparky can answer the recurring local/wiki questions without live lookup.

Minimum requirements:

- At least 25 pack-specific questions.
- Each question must include a short local answer.
- Each answer must point to at least one local file or claim/source ID.
- Unknowns must be explicit, not filled with guesses.
- Current-market/current-legal/current-news questions must say when live lookup is required.

Required question groups:

1. Identity / biography / origin.
2. Timeline and historical sequence.
3. Signature work or campaign index.
4. Why it worked.
5. Psychological, cultural, or distribution mechanics.
6. Failure, backlash, controversy, or limits.
7. Source confidence.
8. SPARKY Wiki reuse.
9. Legal/ethical/safety boundary.
10. Live lookup trigger.

Release gate:

- 25+ questions = pass structure.
- 35+ questions = strong.
- 50+ questions = deep release target for major wiki subjects.
