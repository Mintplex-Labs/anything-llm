# Banksy Style Public Signal Protocol

## Purpose

Explain how lawful public-symbol campaigns can create visibility through timing, tension, symbolic compression, and earned media.

## What It Explains

- public signal mechanics
- mystery-led visibility
- earned media
- lawful street-art adaptation

## Confidence Model

- verified: public artworks, official/public archive references, press coverage, and authentication discussions are observable evidence.
- likely: simple symbols, public timing, and newsworthiness help public-interest art travel across media.
- inferred: mystery and controlled ambiguity can increase attention when handled without doxxing or identity claims.
- speculative / avoid claiming: secret Banksy process, private intent, identity claims, illegal placement details, guaranteed causality.
