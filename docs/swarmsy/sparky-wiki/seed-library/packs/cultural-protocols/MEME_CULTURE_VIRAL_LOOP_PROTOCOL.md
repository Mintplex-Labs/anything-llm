# Meme Culture Viral Loop Protocol

## Purpose

Explain how remixability, emotional compression, participation prompts, and platform-native formats create viral loops.

## What It Explains

- meme culture
- remix loop
- platform spread
- participation mechanic

## Confidence Model

- verified: memes leave public artifacts, repost chains, remixes, and platform traces.
- likely: simple participatory formats spread when audiences can adapt them quickly.
- inferred: strong meme loops give users status, humor, identity, or conflict to perform.
- speculative / avoid claiming: guaranteed virality, hidden algorithm secrets, or universal formulas.
