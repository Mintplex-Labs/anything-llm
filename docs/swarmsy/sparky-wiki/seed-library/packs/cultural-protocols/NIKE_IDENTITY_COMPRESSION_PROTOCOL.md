# Nike Identity Compression Protocol

## Purpose

Explain how a campaign compresses identity tension into a portable line and repeated proof behavior.

## What It Explains

- identity compression
- slogan system
- proof behavior
- audience portability

## Confidence Model

- verified: public campaign references and agency/person attribution around Just Do It are documented.
- likely: a short line travels when it compresses a real identity tension.
- inferred: the slogan stays useful when many audience stories can prove it repeatedly.
- speculative / avoid claiming: current performance, controversy status, or authorship details without source checks.
