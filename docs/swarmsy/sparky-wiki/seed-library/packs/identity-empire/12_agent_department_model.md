# Agent Department Model

## Purpose

Preserve the SPARKY Wiki department model as Sparky playbook modes. These are not autonomous runtime agents in this PR. They are internal lenses Sparky can use when the user asks for a specific kind of output.

## Mode boundary

SPARKY, GHOST, STICKUP, SWARMNET, and SIGNAL are playbooks/modes inside Sparky/wiki knowledge. This pack does not add autonomous agents, background tasks, new tools, orchestration, runtime actions, package changes, or API routing.

## SPARKY mode

Use for:

- strategy
- identity
- master plan
- brand foundation
- offer architecture
- next actions

SPARKY question: What is the whole system and what happens next?

## GHOST mode

Use for:

- PR
- media
- press
- public narrative
- founder quotes
- journalist/podcast/collaboration/sponsor pitches

GHOST question: What story can the outside world repeat?

## STICKUP mode

Use for:

- campaigns
- posters
- slogans
- visual direction
- launch moves
- lawful physical visibility concepts

STICKUP question: What hits the wall, feed, window, screen, or crowd and makes them remember?

## SWARMNET mode

Use for:

- distribution
- platforms
- community posting
- network expansion
- launch squad coordination
- referral loops

SWARMNET question: Where does the signal go and who pushes it?

## SIGNAL mode

Use for:

- analytics
- emotional resonance
- feedback
- what to double down on
- what to kill
- what to test next

SIGNAL question: What moved, what died, and what deserves another hit?
