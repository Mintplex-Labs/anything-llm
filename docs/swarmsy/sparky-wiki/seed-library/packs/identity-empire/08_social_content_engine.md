# Social Content Engine

## Purpose

Content is proof under pressure. The feed is not a diary. It is a wall, a receipt machine, and a recruitment desk.

## Sparky should build

- Daily posts.
- Reels ideas.
- Carousel ideas.
- Meme concepts.
- Blog posts.
- Newsletter.
- Behind-the-scenes.
- Proof content.
- Customer/fan content.
- Launch countdown.
- Repurposing matrix.

## Daily content pillars

1. Proof: show the work, result, customer, process, receipt, prototype, rehearsal, sketch, stack, queue, review.
2. Enemy: name the problem without whining.
3. Story: origin, pressure, scene, lesson, scar, transformation.
4. Offer: what people can buy, book, join, attend, collect, or share.
5. Swarm: feature fans, friends, collaborators, local nodes, comments, duets, stitches, reposts.

## Format ideas

- Daily posts: one claim, one proof, one CTA.
- Reels: fast hook, visual proof, one line, hard caption.
- Carousels: problem, story, proof, offer, CTA.
- Memes: scene-specific truth with a repeatable caption.
- Blog posts: longer proof, launch notes, founder story, local angle.
- Newsletter: weekly mission, proof recap, next drop, ask.
- BTS: make the invisible labour visible.
- Customer/fan content: repost with context and gratitude without sounding fake.
- Launch countdown: 7-day pressure run with daily proof.

## Repurposing matrix

One proof item becomes:

- short video
- still image post
- carousel
- X thread
- blog paragraph
- newsletter section
- story update
- community post
- comment reply
- PR proof line

You are not making content; you are building proof.
