# Empire Brand Builder Playbook

The future Street Swarm builder should be outcome-first. The user describes the brand, app, campaign, workflow, or creator empire they want, and the AI helps assemble the visual system, plans, assets, agents, and launch steps.

## Future Templates

- brand builder
- campaign builder
- creator studio
- Telegram community builder
- merch/ecommerce pack
- content calendar
- AI agent team builder
- launch checklist
- GitHub/Codex repair lane
- website/landing-page planner
- social growth board

## Builder Flow

1. User describes the outcome.
2. Offline App Brain or a live provider clarifies intent.
3. AI assembles a visual plan, workspace structure, tasks, folders, agents, and assets.
4. User previews and approves.
5. AI repairs issues.
6. User exports, publishes, or opens a repair request only after approval.

## Current Boundary

This is doctrine and planning. PR141 does not build Open Runtime, live WYSIWYG editing, source editing, plugin execution, rewards sync, backend changes, Telegram sync, or automatic GitHub/Codex connections.

Offline App Brain — local mini operator remains the baseline for explaining these future templates without requiring any provider.
