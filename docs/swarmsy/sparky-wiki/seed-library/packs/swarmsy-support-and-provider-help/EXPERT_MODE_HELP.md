# Expert Mode Help

Expert Mode is for users who want inspectable mechanics.

## Tools And Surfaces

- Diagnostics: local status, provider configured flags, app safety state.
- Logs: useful for launcher, provider, and local runtime troubleshooting.
- Tests: validation commands before release or PR review.
- Branches: sandbox-first repair and feature work.
- PRs: reviewable changes, validation output, risks, and manual QA evidence.
- Provider routing: Local Brain, OpenAI/GPT, local wiki/reference layer, and future Grok/xAI boundaries.
- Codex/GitHub repair lane: future code repair, diffs, tests, issue/PR/review workflows.

## Future Source Edit Mode

Source edit mode is future only. It must be opt-in, sandbox-first, rollback-first, and explicit about tests, diffs, and PR drafts.

It must not silently publish to official master, expose secrets, change rewards/backend/Telegram authority, or connect GitHub/Codex automatically.

## Browser-First Alpha

Expert troubleshooting should validate the browser runtime first. Electron shell remains experimental until interaction QA passes there.

## Provider Failures

When providers fail, use the Provider Failure Playbook and keep local wiki/reference layer — local mini operator active as the baseline guidance layer.
