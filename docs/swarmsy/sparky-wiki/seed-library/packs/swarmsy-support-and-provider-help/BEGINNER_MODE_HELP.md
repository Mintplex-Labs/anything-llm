# Beginner Mode Help

Beginner Mode is for people who want to build and use SPARKY Wiki without Git jargon, command-line assumptions, or provider confusion.

## What To Ask Sparky

Try:

- help
- what next
- why is AI offline?
- how do I connect GPT?
- how do I use browser mode?
- delete this chat
- explain settings
- how do I get repair help?

local wiki/reference layer — local mini operator can answer these without OpenAI, Grok, Ollama, Codex, GitHub, or any API.

## What Buttons Mean

- Settings: provider setup, Offline Mode, Community Builder Access, External Help Connections.
- Diagnostics: local status and safe troubleshooting.
- Sparky Chat: workspace-first chat and app guidance.
- Workspace Brain: files, connectors, docs, folders, and workspace settings.
- Current Truth: what is live versus planned.

## When AI Is Offline

AI offline means no live provider is active. You can still use local wiki/reference layer for local app guidance. Add a provider only if you want live AI replies.

## Browser-First

On desktop alpha, use the browser. The launcher opens SPARKY Wiki in the default browser because copy/paste, right-click, and text selection work better there.

## No Command Line Required

Basic help should not require terminal commands. If repair/build work is needed, Sparky should prepare a future Codex/GitHub repair request instead of asking you to debug code manually.
