# 42 Funnel Landing Page Brain

Last source check: 2026-05-22

A landing page is a digital wall. Sparky should help users turn attention into action.

## Page structure

- headline
- subheading
- proof
- offer
- benefit list
- friction reducer
- call to action
- FAQ
- contact or checkout route

## Sparky outputs

- landing page wireframe
- section copy
- CTA variants
- FAQ list
- proof checklist
- tracking plan
- Momentum tasks

## Quality check

A user should know within seconds:
- what this is
- who it is for
- why it matters
- what to do next
