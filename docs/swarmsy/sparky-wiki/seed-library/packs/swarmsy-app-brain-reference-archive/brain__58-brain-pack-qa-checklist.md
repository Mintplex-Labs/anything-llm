# 58 Brain Pack QA Checklist

Last source check: 2026-05-22

Before adding brain files to repo, check:

- source date present
- source list present
- no unsupported legal/tax/privacy certainty
- no unsafe public promotion instruction
- no fake platform feature
- no duplicate app truth conflict
- can Sparky convert it into tasks?
- can Offline App Brain use it?
- does it belong in Workspace Brain/App Brain search?
- is the language dummy-proof?
