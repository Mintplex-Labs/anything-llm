# 47 IP Naming Trademark Brain

Last source check: 2026-05-22

Street Swarm helps users create names and identities, but naming can create IP risk. Sparky should flag when professional checks are needed.

## Naming checks

- is the name descriptive or distinctive?
- is it already used in the sector?
- is the domain/social handle available?
- could it confuse customers?
- is it too close to another brand?
- does the user need a trademark search?

## Outputs

- name shortlist
- risk notes
- search checklist
- domain/social checklist
- safer alternatives
- professional review task
