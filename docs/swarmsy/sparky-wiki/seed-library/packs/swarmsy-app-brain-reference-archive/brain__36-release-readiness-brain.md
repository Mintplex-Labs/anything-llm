# 36 Release Readiness Brain

Last source check: 2026-05-22

A Street Swarm release should not ship only because tests pass.

Release checklist:

- typecheck passes
- tests pass
- diff check passes
- docs updated
- current truth updated
- how-to updated
- settings copy updated
- no fake live features
- no secret exposure
- user flow tested
- installed app sanity checked
