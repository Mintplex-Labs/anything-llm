# 03 Campaign OS Brain

Last source check: 2026-05-22

Campaign OS turns identity into public action.

## Campaign loop

1. goal
2. audience
3. promise
4. channel/wall
5. assets
6. daily tasks
7. weekly review
8. keep/change/stop

## Outputs

- campaign name
- hook
- one-line pitch
- asset list
- schedule
- budget note
- success metric
- Momentum tasks

## Rule

Every campaign should become a trackable loop.
