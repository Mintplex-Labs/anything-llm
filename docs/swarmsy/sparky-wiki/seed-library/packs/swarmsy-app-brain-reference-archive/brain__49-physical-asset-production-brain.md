# 49 Physical Asset Production Brain

Last source check: 2026-05-22

Street Swarm can help users create physical campaign assets responsibly.

## Asset types

- flyers
- posters
- cards
- stickers for lawful use
- banners
- signs
- shop window graphics
- event boards
- packaging inserts
- QR cards

## Production checklist

- size
- material
- quantity
- budget
- deadline
- permission/use location
- QR destination
- accessibility/readability
- removal plan if temporary

## Outputs

- print brief
- supplier question list
- cost estimate prompt
- distribution plan
- legal/permission reminder
- Momentum tasks
