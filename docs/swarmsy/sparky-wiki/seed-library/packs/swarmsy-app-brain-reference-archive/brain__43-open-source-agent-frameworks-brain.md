# 43 Open Source Agent Frameworks Brain

Last source check: 2026-05-22

Street Swarm should learn from current agent frameworks without becoming a fragile autonomous mess.

## Framework patterns to reuse

- LangGraph: graph/state-machine workflows with explicit control.
- CrewAI: role/task team structure.
- AutoGen: multi-agent conversation and tool-use patterns.
- Agno: lightweight agent/tool orchestration patterns.
- Semantic Kernel: skills/functions/connectors.
- AgentForge-style design: declarative skills, tool contracts, backend switching.
- AgentGit-style idea: branch/revert/compare agent trajectories.

## Street Swarm fit

Use these concepts inside app features:

- Sparky supervisor
- Identity Forge specialist
- Campaign OS specialist
- SEO specialist
- Budget Beast specialist
- Brand Doctor specialist
- Repair Desk specialist
- Safety/compliance reviewer
- Momentum manager

## Hard rule

No autonomous live action without user approval. Agents can propose, draft, preview, and create local tasks. They do not silently publish, spend, sync, or mutate official core.
