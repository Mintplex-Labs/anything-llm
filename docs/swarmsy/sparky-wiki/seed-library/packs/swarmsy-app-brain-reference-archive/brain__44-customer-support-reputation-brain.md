# 44 Customer Support Reputation Brain

Last source check: 2026-05-22

Visibility creates attention, and attention creates support needs. Sparky should help users protect reputation by responding clearly and quickly.

## Support loop

- receive issue
- classify issue
- respond calmly
- solve or escalate
- document outcome
- review pattern
- improve process

## Outputs

- customer reply
- refund/return question list
- apology draft
- escalation note
- FAQ update
- reputation risk flag
- Momentum task

## Tone rules

- clear
- calm
- honest
- no blame
- no false promises
- record what happened
