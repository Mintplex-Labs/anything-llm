# 53 Knowledge Graph Entity Brain

Last source check: 2026-05-22

Street Swarm should eventually connect documents, tasks, identities, campaigns, sources, and rewards as entities.

## Entity types

- workspace
- brand
- identity DNA
- campaign
- document
- source
- task
- reward event
- contact
- asset
- post
- budget item
- search keyword

## Relationships

- task belongs to campaign
- campaign uses identity DNA
- document supports answer
- source proves claim
- reward event comes from task
- asset belongs to campaign
- keyword belongs to brand

## Benefit

Sparky can answer:

- What is this campaign built from?
- What proof supports this?
- What tasks are blocking launch?
- What should be reused?
