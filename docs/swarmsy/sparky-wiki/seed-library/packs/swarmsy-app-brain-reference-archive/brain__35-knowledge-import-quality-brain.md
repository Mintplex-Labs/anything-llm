# 35 Knowledge Import Quality Brain

Last source check: 2026-05-22

Workspace Brain can import text, URLs, and public repositories. Users need quality signals.

Quality checks:

- source authority
- date
- duplication
- missing context
- source type
- possible bias
- stale guidance
- unsafe secrets
- import errors

- indexed
- failed
- skipped
