# 57 Street Swarm Product Doctrine Brain

Last source check: 2026-05-22

This app exists to help users become visible, memorable, and operational.

## Product doctrine

- identity first
- workspace scoped
- local-first
- dummy-proof UI
- real tasks, not only chat
- docs updated with user flow
- working vs coming soon always clear
- no duplicate reward backend
- Telegram/web identity is reward truth
- official core protected
- local custom build layer planned

## Build question

Before adding any feature, ask:

Does this help the user become more visible, more organised, more memorable, or more capable?

If not, it is probably drift.
