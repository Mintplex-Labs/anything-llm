# 28 Local Custom Build Mode Brain

Last source check: 2026-05-22

Local Custom Build Mode lets advanced users modify their own local app experience while keeping the official core protected.

Official core:

- release app
- sync rules
- reward truth
- safety boundary

Local override layer:

- UI changes
- themes
- layouts
- workflow tests
- patch history

Controls:

- preview patch
- apply locally
- rollback
- save custom build
- reset to official
- send to GitHub
