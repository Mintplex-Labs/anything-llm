# 45 Structured Output Contracts Brain

Last source check: 2026-05-22

Street Swarm should use structured outputs wherever the app needs reliable data instead of prose.

## Use structured outputs for

- Identity Forge profiles
- Campaign plans
- Budget Beast calculations
- Momentum tasks
- Brand Doctor scores
- SEO keyword clusters
- Workspace import summaries
- repair reports
- local custom patch proposals

## Contract rule

Every agent tool should define:

- input schema
- output schema
- validation
- fallback path
- user-visible error
- test fixture

## Offline use

When no AI is available, deterministic compilers should create the same schemas with simpler content.
