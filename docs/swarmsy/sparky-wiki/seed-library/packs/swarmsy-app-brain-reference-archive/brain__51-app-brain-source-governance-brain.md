# 51 App Brain Source Governance Brain

Last source check: 2026-05-22

As the app brain grows, it needs source governance so bad or stale content does not dominate answers.

## Source classes

- root truth docs
- brain pack docs
- user imports
- website wiki truth
- public web pages
- public GitHub repos
- Momentum tasks
- Identity Creative DNA

## Trust order

For product truth:

1. root truth docs
2. current repo docs
3. branch/PR notes
4. user instructions
5. older docs marked historical

For external facts:

1. official source
2. regulator/platform docs
3. primary company docs
4. reputable industry body
5. commentary

## Expiry

High-risk sources need refresh dates. Old sources can be used for background, not current claims.
