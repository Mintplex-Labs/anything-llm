# 50 AI Visibility Entities Schema Brain

Last source check: 2026-05-22

AI visibility depends on clear entity facts that machines and people can understand.

## Entity facts

- name
- description
- category
- location or service area
- founder/creator if public
- offer
- proof
- official links
- social links
- contact route

## Outputs

- entity profile
- FAQ
- About page
- structured data plan
- source citation list
- consistency checklist
- Momentum tasks

## Rule

Do not invent entity facts. Ask user to confirm official facts before publishing.
