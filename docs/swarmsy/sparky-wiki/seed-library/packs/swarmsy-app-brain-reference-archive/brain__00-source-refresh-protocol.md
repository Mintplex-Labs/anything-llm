# 00 Source Refresh Protocol Brain

Last source check: 2026-05-22

Street Swarm brain files must not go stale. Any file touching law, finance, privacy, platform rules, live APIs, model/runtime behaviour, advertising, consumer rights, or safety needs a source refresh before being treated as current truth.

## Source priority

1. Official government/regulator docs
2. Official platform/product docs
3. Standards bodies
4. Industry bodies
5. Reputable trade sources
6. Commentary, clearly marked as interpretation
7. User docs, clearly marked as user-provided source

## Required metadata

Each brain file should carry:
- last source check
- source risk
- brain category
- tags
- whether it is canon, playbook, documentary, red-team, runtime, or sandbox expansion

## App rule

Sparky can use stale files for historical context, but must not claim current law/platform/API truth from stale files.
