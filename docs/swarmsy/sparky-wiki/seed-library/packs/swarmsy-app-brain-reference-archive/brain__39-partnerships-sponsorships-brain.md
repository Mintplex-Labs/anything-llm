# 39 Partnerships Sponsorships Brain

Last source check: 2026-05-22

Street Swarm should help users create simple, honest partnership and sponsorship proposals.

Inputs:

- partner target
- shared audience
- benefit to partner
- benefit to user
- campaign idea
- deliverables
- dates
- proof
- budget or value exchange

Rule: do not promise reach, sales, or results without evidence.
