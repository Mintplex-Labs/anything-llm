# 32 PR Publicity Press Brain

Last source check: 2026-05-22

Street Swarm should help users turn meaningful activity into press-ready stories.

PR angle types:

- local impact
- founder story
- unusual launch
- community benefit
- event
- creative project
- partnership
- milestone
- data/result

Rule: do not invent facts, results, partnerships, awards, or press interest.
