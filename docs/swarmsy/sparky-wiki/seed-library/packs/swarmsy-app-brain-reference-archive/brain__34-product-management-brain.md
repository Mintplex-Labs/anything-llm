# 34 Product Management Brain

Last source check: 2026-05-22

Street Swarm itself should be built with product discipline.

Product loop:

- user problem
- user segment
- solution
- smallest useful version
- test
- feedback
- improve
- remove what fails

Every new feature needs:

- user purpose
- working state
- coming soon state
- help copy
- test guard
- rollback or remove path
