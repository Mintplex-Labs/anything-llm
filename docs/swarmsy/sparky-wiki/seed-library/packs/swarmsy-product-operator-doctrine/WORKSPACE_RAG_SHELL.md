# Workspace RAG Shell

Status: browser-first Workspace Brain foundation. This is not Open Runtime, a source editor, reward sync, backend work, Telegram sync, or website work.

The Workspace RAG shell is the SPARKY Wiki-owned version of the workspace/document/connectors model:

- Workspace
- Documents
- Data Connectors
- Chat Settings
- Vector DB status
- Agent Configuration

## What Is Live Or Foundation

- Workspace list, create/select, local title/summary records, and counts.
- Linked chat count, document count, connector count, and agent count.
- Documents panel state from local workspace document records, indexed documents, and source registry entries.
- Data Connector registry slots with safe status labels.
- Settings tabs for General Settings, Chat Settings, Vector Database / Retrieval Settings, and Agent Configuration.
- Vector DB status labeled as `planned-local`/foundation, not fake cloud.
- Agent Configuration foundation under Sparky governance.

## Connector Slots

- GitHub Repo: foundation slot for existing safe public-repo import flow.
- GitLab Repo: planned.
- YouTube Transcript: planned.
- Bulk Link Scraper: foundation slot for existing public URL ingestion flow.
- Obsidian: planned.
- Local Folder: planned.
- Manual URL: foundation slot for existing local source/URL flow.

No connector should display secrets, pretend to scrape, or call unsupported backends.
