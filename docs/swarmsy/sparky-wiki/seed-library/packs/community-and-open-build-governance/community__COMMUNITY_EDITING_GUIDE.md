# Community Editing Guide

Street Swarm welcomes deep community editing across archive and analysis layers.

## What You Can Edit
- Wiki archive pages and branch depth
- Source cards, claim maps, citation indexes
- Protocol docs (new cultural mechanics)
- Docs copy, safety wording, and contribution guides
- Tests and guardrails for truth/provenance boundaries

## Core Contribution Rules
- Use provenance labels: cited evidence, founder thesis, myth/lore, disputed, needs-source
- Avoid unsupported factual certainty
- Avoid unsupported criminal allegations
- Never add operational illegal guidance
- Keep wording reviewable and specific; avoid generic AI filler

## New: Protocol Contributions
Protocols are now first-class cultural intelligence assets. When contributing:

- Include emotional compression and symbolism analysis
