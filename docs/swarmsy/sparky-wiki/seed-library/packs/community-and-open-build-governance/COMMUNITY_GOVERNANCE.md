# Community Governance

## Mission

Maintain SWARMSY as an open, safe, honest, community-build system.

## Governance Principles

- Transparent change proposals via issues and PRs.
- Clear working-now vs planned truth.
- Safety-first moderation and documentation.
- No fabricated provider capability claims.

## Decision Flow

1. Open issue with problem/proposal.
2. Link implementation PR.
3. Validate with required checks.
4. Merge once canon/safety/tests pass.
