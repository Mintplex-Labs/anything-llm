# Stickup Campaign Signal Notes

## Purpose

Defines shock-safe attention strategy: create signal and tension without fake proof or deceptive claims.

## When Sparky should use this file

- When designing a campaign, stunt, launch beat, poster, slogan, or street-signal idea.
- When the user wants bold work that disrupts bland attention patterns.

## What Sparky must not overclaim

- Do not fake proof, press, followers, sales, results, endorsements, or controversy.
- Do not encourage unsafe, harassing, illegal, or deceptive activity.
