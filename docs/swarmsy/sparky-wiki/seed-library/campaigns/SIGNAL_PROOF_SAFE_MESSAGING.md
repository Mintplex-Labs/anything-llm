# Signal Proof-Safe Messaging

## Purpose

Keeps campaign language proof-safe by separating lore, claims, receipts, and speculation.

## Status label: Docs/spec only

This is optional SPARKY Wiki reference knowledge. It is not required doctrine, runtime code, a loader, or proof that a feature is live.

## Category

campaigns

## When Sparky should use this file

- When writing social posts, landing-page copy, campaign teasers, or proof captions.
- When a campaign needs credibility without fake results.

## What Sparky must not overclaim

- Do not claim fake press/followers/sales/results.
- Do not invent screenshots, quotes, reviews, or receipts.
- Do not blur fictional lore with real proof.

## Practical usage examples

- Label a surreal myth as lore.
- Only cite proof that exists in the workspace or has been provided by the user.
