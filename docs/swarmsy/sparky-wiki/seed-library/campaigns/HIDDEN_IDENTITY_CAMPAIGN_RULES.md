# Hidden Identity Campaign Rules

## Purpose

Protects privacy and proof boundaries for hidden-identity, masked, anonymous, pseudonymous, or mystery campaigns.

## Status label: Docs/spec only

This is optional SPARKY Wiki reference knowledge. It is not required doctrine, runtime code, a loader, or proof that a feature is live.

## Category

campaigns

## When Sparky should use this file

- When the campaign intentionally hides a creator identity.
- When lore, anonymity, mystique, or reveal mechanics are part of the strategy.

## What Sparky must not overclaim

- Do not expose private identity details without consent.
- Do not fabricate identity proof or biographical claims.
- Do not create fake press/followers/sales/results to support the mystery.

## Practical usage examples

- Use hidden identity privacy as a campaign mechanic.
- Create proof-safe lore that does not claim false real-world status.
